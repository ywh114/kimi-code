# Fork Patches

Short log of patches applied on top of upstream `kimi-code`.

| Patch | Description | Files |
|-------|-------------|-------|
| Remove tips | Disabled rotating toolbar tips above the input box and tips next to the streaming spinner. | `src/tui/components/chrome/footer.ts`, `src/tui/components/chrome/header.ts` |
| Live-thinking expansion (Ctrl+Y) | `Ctrl+Y` expands/collapses reasoning while it is streaming; finalized blocks are unaffected. Expanded live thinking uses a static bullet instead of the animated Braille spinner to stop flashing. `Ctrl+E` is left free for end-of-line. | `src/tui/components/messages/thinking.ts`, `src/tui/components/editor/custom-editor.ts`, `src/tui/components/dialogs/help-panel.ts` |
| Finalize thinking before tool calls | Live thinking blocks are finalized before a tool call renders, so tool output updates do not fight with expanded thinking. | `src/tui/controllers/session-event-handler.ts` |
| Footer badges | Added `xtool` and `xthink` indicators next to `yolo`/`plan`. | `src/tui/types.ts`, `src/tui/kimi-tui.ts`, `src/tui/controllers/streaming-ui.ts`, `src/tui/components/chrome/footer.ts` |
| Symbols / spinners | Status bullet changed from `●` to legacy `•`. Braille/moon spinners replaced with ASCII `| / - \\` to avoid missing-glyph boxes. | `src/tui/constant/symbols.ts`, `src/tui/constant/rendering.ts` |
| Sticky shell mode (`Ctrl+X`) | `Ctrl+X` toggles bash mode; submits stay in shell mode until toggled off. | `src/tui/controllers/editor-keyboard.ts`, `src/tui/components/editor/custom-editor.ts` |
| Bash prompt symbol | Bash-mode prompt changed from `!` to `$`. | `src/tui/components/editor/custom-editor.ts` |
| `!!` direct shell eval | `!!<cmd>` runs Bash directly via `session.runShellCommand`, streams output to a `SHELL` panel, prompt shows `&`, output is deduplicated, and `Esc` closes the panel. | `src/tui/components/editor/custom-editor.ts`, `src/tui/kimi-tui.ts`, `src/tui/controllers/shell-eval-panel.ts`, `src/tui/components/panes/shell-eval-panel.ts` |
| `/help` shortcuts | Added `Ctrl+Y` (live thinking), `Ctrl+X` (shell mode), and `Ctrl+R` (reverse-i-search) to the `/help` keyboard list, and corrected the `Esc` description. | `src/tui/components/dialogs/help-panel.ts` |
| Reverse-i-search (`Ctrl+R`) | `Ctrl+R` starts a reverse history search; repeated `Ctrl+R` cycles older matches, `Enter` accepts, `Esc`/`Ctrl+C`/`Ctrl+G` cancel. The search query is edited in the input line with a `?` prompt, and the matched history entry is shown as a dim hint. All search updates force a full redraw so stale frames are not left behind while the transcript scrolls. | `src/tui/components/editor/custom-editor.ts`, `packages/pi-tui/src/components/editor.ts` |
| `/context-max` command | New slash command to cap the effective context window of the current model: `/context-max 256k` (also `128k`, `512k`, `1M`, raw numbers), `/context-max reset`, and no-arg status. Writes `models.<alias>.overrides.maxContextSize` to config.toml (preserved across managed catalog refreshes); the running session picks it up immediately because `ProviderManager` reads config live, and the footer gauge is refreshed from `session.getStatus()`. Auto-compaction then triggers at ~85% of the cap (minus the 50k reserve), lowering per-turn input-token spend on long sessions. | `src/tui/commands/config.ts`, `src/tui/commands/registry.ts`, `src/tui/commands/dispatch.ts`, `src/tui/commands/index.ts` |
| Force truecolor | `chalk.level = 3` when stdout is a TTY. chalk auto-detects level 2 when `COLORTERM` is unset (e.g. inside tmux with `TERM=screen/tmux-256color`), flattening custom theme hexes into muddy 256-cube approximations (thinking `#928374` gray became khaki). | `src/tui/theme/theme.ts` |
| `Esc` vs `Ctrl-C` | `Esc` only closes dialogs/panels and double-tap undo; it no longer cancels streaming/compaction/`/init`. `Ctrl-C` handles all interruption. Error messages that suggested `Esc or Ctrl-C` now say `Ctrl-C`. | `src/tui/controllers/editor-keyboard.ts`, `src/tui/kimi-tui.ts`, `src/tui/commands/resolve.ts`, `src/tui/commands/config.ts`, `src/tui/commands/undo.ts` |
| Subagent model selection (`[subagent.models]`) | Per-profile model overrides for subagents: `[subagent.models]` in config.toml maps profile names (`coder`, `explore`, `plan`) to aliases from `[models]`, e.g. `coder = "kimi-for-coding"` to offload coding loops to a cheaper model while the main session plans on a stronger one. Spawn, resume, and retry resolve via `resolveSubagentModelAlias`; profiles without an entry inherit the parent model, and an entry naming an unconfigured alias falls back to the parent model with a warning. Applies to `Agent`/`AgentSwarm`, foreground and background; `/btw` side questions always use the parent model. Read from the session-bound config snapshot, so edits take effect for sessions started after the change. | `packages/agent-core/src/config/schema.ts`, `packages/agent-core/src/session/subagent-host.ts` |
| Delete sessions in `/sessions` | `Ctrl+K` in the session picker arms a delete for the selected session (`Delete "<title>"? Ctrl+K confirm · Esc cancel`); a second `Ctrl+K` confirms, any other key cancels, and the current session is refused. The backend (`deleteSession` RPC, `SessionStore.delete`, SDK wrapper) landed upstream between rebases and uses append-only tombstone records in `session_index.jsonl`; this patch adds the `/sessions` TUI binding and tests on top of it. After deletion the picker refreshes and moves the selection to the neighboring session. | `src/tui/components/dialogs/session-picker.ts`, `src/tui/kimi-tui.ts`, `packages/agent-core/test/session/store.test.ts`, `test/tui/components/dialogs/session-picker.test.ts` |
| `critic` / `brainstorm` subagent profiles | Two read-only subagent profiles for second opinions: `critic` adversarially reviews plans/designs/code changes; `brainstorm` generates independent options and is told to ignore any tentative approach embedded in the caller's prompt (callers should describe problem + constraints only). Registered in `agent.yaml` so the `Agent` tool lists them; they run on whatever model `[subagent.models]` maps them to. | `packages/agent-core/src/profile/default/critic.yaml`, `packages/agent-core/src/profile/default/brainstorm.yaml`, `packages/agent-core/src/profile/default/agent.yaml`, `packages/agent-core/src/profile/default.ts` |
| Ctrl+O / Ctrl+Y independence | `toggleToolOutputExpansion` used to call `setExpanded(false)` on every expandable component, so toggling Ctrl+O off collapsed live thinking even when the Ctrl+Y lock was on. Thinking components now keep `expanded || thinkingExpandedLocked` during the Ctrl+O sweep; the two toggles are fully independent. | `src/tui/kimi-tui.ts` |
| Tool-arg type coercion | Some models (Qwen previews) emit numeric tool arguments as JSON strings (`"255"` instead of `255`), which Ajv's strict `type: integer` rejected — e.g. Read's `line_offset` failed with "must be integer". Enabled Ajv `coerceTypes` on all three draft validators, so stringified numbers are coerced to the schema's declared type in place (the validated object is the same reference the tool executes with). Coercion only fires for non-string schema types, so genuine string fields are untouched. | `packages/agent-core/src/tools/args-validator.ts` |
| Subagent detail panel (`Ctrl+↓` / `Ctrl+↑`) | opencode-style child view: `Ctrl+↓` opens a read-only panel showing one subagent's full detail (thinking, text, sub-tool calls, result/error, tokens); `Ctrl+↑`/`Ctrl+↓` and `←`/`→` walk the flat chronological list of agent cards — standalone Agent cards and AgentGroup (swarm) members, which sit adjacently so `←`/`→` naturally cycles parallel subagents. Opens scrolled to the bottom and follows the tail of a running agent until you scroll up (scrolling back down re-arms it). `↑`/`↓` (empty editor) scrolls, `Esc`/`Ctrl+C` closes. While open, the panel re-polls `ToolCallComponent.getSubagentDetail()` every 500ms so running agents stay live; replayed sessions work through the same accessor. | `src/tui/components/messages/tool-call.ts`, `src/tui/components/panes/subagent-detail-panel.ts`, `src/tui/controllers/subagent-detail.ts`, `src/tui/controllers/editor-keyboard.ts`, `src/tui/components/editor/custom-editor.ts`, `src/tui/tui-state.ts`, `src/tui/kimi-tui.ts` |
| `api_key_env` provider field | New optional provider field `api_key_env = "VAR_NAME"`: the API key is read from that shell environment variable at resolution time, so keys never live in config.toml. Consulted last, after `api_key` and the `[providers.<name>.env]` sub-table (which upstream defines as literal values, not env pointers). | `packages/agent-core/src/config/schema.ts`, `packages/agent-core/src/session/provider-manager.ts` |
| Suspend keep-alive | Fixes intermittent death on `Ctrl+Z`/`fg`: after `ui.stop()` tears down stdin/render/tracking handles, an idle app can have zero event-loop handles left, so Node exited (code 0) in the window before the self-SIGSTOP took effect. A no-op `setInterval` is now armed in the SIGTSTP handler before `ui.stop()` and cleared in the SIGCONT handler (and in `stop()`), guaranteeing the process survives until it actually stops. Diagnosed via gdb + ptrace signal tracing; note bash 5.3 reports a stopped job as `EXIT=147` in a `;` list, which masquerades as a crash. | `src/tui/kimi-tui.ts` |
| Compaction file tracking | Ported from pi's structured compaction, keeping kimi-code's free-form note: after each compaction, tool calls in the compacted history are scanned for file paths (Read/ReadMediaFile/Grep/Glob → read; Write/Edit → modified), unioned with the lists parsed from the previous summary, and appended as `<read-files>` / `<modified-files>` blocks. The lists live in the summary text itself, so no record-schema change is needed, the union survives successive compactions and session restore, and the TUI compaction card shows them. Lists are capped at 300 entries each (oldest dropped). The instruction tells the summarizer not to transcribe the blocks. | `packages/agent-core/src/agent/compaction/file-tracking.ts`, `packages/agent-core/src/agent/compaction/full.ts`, `packages/agent-core/src/agent/compaction/compaction-instruction.md` |
| Tests | Updated tests for the above changes. | `test/tui/controllers/editor-keyboard.test.ts`, `test/tui/kimi-tui-message-flow.test.ts`, `test/tui/components/editor/custom-editor.test.ts`, `test/tui/components/panels/help-panel.test.ts`, `test/tui/commands/context-max.test.ts`, `packages/agent-core/test/session/subagent-host.test.ts`, `packages/agent-core/test/config/configs.test.ts`, `packages/agent-core/test/session/store.test.ts`, `test/tui/components/dialogs/session-picker.test.ts`, `packages/agent-core/test/profile/default-agent-profiles.test.ts`, `packages/agent-core/test/harness/runtime-provider.test.ts`, `packages/agent-core/test/agent/compaction/file-tracking.test.ts`, `packages/agent-core/test/agent/compaction/full.test.ts`, `test/tui/components/chrome/welcome.test.ts`, `test/tui/create-tui-state.test.ts`, `test/tui/controllers/subagent-detail.test.ts`, `test/tui/components/panes/subagent-detail-panel.test.ts`, `test/tui/controllers/editor-keyboard-image-paste.test.ts`, `packages/agent-core/test/tools/args-validator.test.ts` |
